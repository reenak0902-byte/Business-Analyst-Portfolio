# Business-Analyst-Portfolio

## Amazon Leather Handicraft Sales Dashboard

### Project Overview
This Power BI dashboard analyzes Amazon Leather Handicraft sales to provide insights into revenue, customer behavior, product performance, and sales trends.

### Tools Used
- Power BI
- DAX
- Power Query

### Key KPIs
- Total Revenue
- Total Orders
- Total Units Sold
- Average Order Value

### Dashboard Pages
1. Sales Overview
2. Customer Insights
3. Product Performance
